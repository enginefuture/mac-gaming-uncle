# Mac Gaming Uncle 0.4.0 — compatibility and launch feedback

This is a research preview for Apple Silicon and macOS 15+. English and Simplified Chinese are included.

## Changes

- Library installation status now checks Steam download/staging counters and committed installation state before enabling Play.
- Start Game shows launching/running feedback and prevents repeated launch requests.
- Dota 2 compatibility recipe selects the appropriate D3DMetal path and repairs fullscreen configuration; microphone usage descriptions address the observed voice-privacy crash path.
- Grim Dawn display configuration handles CRLF/duplicate keys, Retina policy, and shared Steam display-session changes more consistently.
- Experimental universal 2× interpolation (macOS 26+) can follow a configured game's foreground window. It is OFF by default, with an emergency stop and fallback to the original view.

## Downloads

Download **Mac-Gaming-Uncle-0.4.0-macOS-arm64.dmg**, drag the app to Applications, and replace the previous app after exiting games and Mac Gaming Uncle. Keep application data to retain installed components and games.

Wine 11.0.2 is supplied as a separate runtime attachment, unchanged from 0.3.0. It is downloaded automatically by the application. SHA-256 files accompany both artifacts. No Apple GPTK image or game files are bundled in the DMG.

This preview is **ad-hoc signed and not notarized by Apple**. See the README installation guide for macOS security prompts; do not disable system protection.

## Known limitations

- Interpolation is experimental, SDR/windowed/borderless only, and requires screen-capture permission. It can add latency or distort moving HUD/particles. Submission counts are not physical display FPS, and FPS doubling is not guaranteed.
- On the tested M3 Max/macOS 26.6.2 system, 720p interpolation worked but 1080p and a decorated 1280×752 capture failed. Unsupported captures return to the original view without automatic downscaling.
- 4×, static-detail recovery, and the Godot test project are not advertised app features or included game content.
- Dota 2 background-music artifacts and variable gameplay performance are not declared fully resolved. Compatibility varies by title and configuration.
